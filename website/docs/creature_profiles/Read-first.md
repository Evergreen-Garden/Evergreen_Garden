# Read First

Evergreen Garden is a soft realism server with an emphasis on speculative, but natural behaviour. To provide a naturalistic experience we have made roleplaying *profiles* for each animal that inhabits the Garden.

Profiles are rules and roleplaying suggestions, instructions on how you should play each separate animal in the Evergreen Garden. Some rules are mandatory(hard rules), some are optional(soft rules):

## Soft rules
- Nesting locations 🪺;
- Preferred habitats 🌵;
- Sexual dimorphism ⚧️;
- Most roleplaying guidelines and neutral interactions 🦚;

Soft rules are optional roleplay flavour that you may chose to ignore. If you want to roleplay in a way that differs from the profile, you are free to do so! Existing guidelines are there to provide fun roleplaying options and create a plausible semi-realistic environment;

## Hard rules
- Group sizes 🔢;
- Mixpacking options 🔄;
- Conflict rules ⚔️;
- __Highlighted__ (imperative) guidelines ❗ ;

Hard rules are gameplay restrictions set in place to create a fair and balanced experience. They mostly concern grouping, who you can and can’t fight, and in very rare cases, banned behaviours. Breaking hard rules may result in getting a yellow card warning!

We kindly ask you to quickly read the profile of any animal you are planning to play! We tried our best to make the profiles as easy to navigate and read as possible, and following them will elevate the gameplay experience for all players.

## Tags

The following is a descriptive list of all tags we use in our profiles:

- Size
What Size-class the particular profile belongs to

- 🚢  Combat Rule: Water 
This creature can 3rd party near water.

- ⚔️ Combat Rule: Special
This creature has special combat rules and may act outside of common behaviour

- 🔴 (D)anger Level: High
This creature does _not_ need to challenge before attacking

- 🥷🏻 Scavenger:
Can steal resources from a claimed resource without needing to challenge.

- 🫡 Offensive Mixpack:
This creature has the ability to mixpack while showing agressive behaviour.
